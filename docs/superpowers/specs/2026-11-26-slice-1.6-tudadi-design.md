# Slice 1.6: the thematic zero-grade class (tudādi), present and past imperfective

Short design, agreed in conversation on 2026-11-26. It builds on the slice-1 design
(`2026-11-24-prakriya-engine-design.md`) and slice 1.5
(`2026-11-25-slice-1.5-bhvadi-design.md`). Everything there still holds unless this
document says otherwise.

## Intent

A quick slice to get the second thematic class out of the way before slice 2.0
(athematic-root-core: a handful of adādi roots traced and hand-checked, then the
whole class). Tudādi differs from bhvādi mainly in one thing: its thematic affix śa
counts as marked ṅ (1.2.4 sārvadhātukam apit), so 1.1.5 kṅiti ca blocks full grade
and the root stays in zero grade (tudáti, not *todati). Watching that block happen,
with the reason cited, is the point. The same 1.2.4 + 1.1.5 mechanism drives the
strong/weak alternation in slice 2.0, so this slice also rehearses it.

The derivation search (extended siddha, Joshi & Kiparsky) stays deferred until a
covered form needs it.

## Scope

- **In:** every root in the tudādi section of the root list (174 entries, codes
  `06.`), laṭ and laṅ, the voices their markers allow. Same request space as
  slice 1.5: no preverbs, no accent, restricted siddha principle.
- **Out:** anything a sweep shows needs a derived stem or athematic machinery
  gets an `availability()` reason with the governing sūtra, as in slice 1.5. None
  is expected.

## New rules

From a Vidyut laṭ 3sg sweep of the 174 roots (rules cited there but never in
bhvādi). Counts are forms over both voices.

| Rule | What it does | Examples |
|---|---|---|
| 3.1.77 tudādibhyaḥ śaḥ | thematic affix śa instead of śap | all |
| 7.1.59 śe mucādīnām | nasal infix before śa, 8 roots | muñcati, lumpati, vindati, siñcati, kṛntati |
| 7.1.59.1 (vārttika) śe tṛmphādīnāṃ num vācyaḥ | the same for the tṛmphādi roots; 6.4.24 is the rule it overrides | tṛmphati, gumphati, umbhati |
| 6.4.77 aci śnudhātubhruvāṃ yvor iyaṅuvaṅau | i/u → iy/uv before a vowel | dhuvati, kṣiyati, nuvati |
| 6.1.16 grahijyāvayivyadhi… + 6.1.108 samprasāraṇāc ca | y/r/v weaken to i/ṛ/u before a ṅit affix | pṛcchati, vṛścati, vicati, bhṛjjati |
| 7.4.28 riṅ śayagliṅkṣu | ṛ → ri before śa | mriyate, dhriyate, driyate |
| 7.1.100 ṝta id dhātoḥ (+ 1.1.51 uraṇ raparaḥ) | ṝ → ir | kirati, girati |
| 8.2.21 aci vibhāṣā | optional r → l for gṝ | gilati / girati |
| 8.2.79 na bhakurchurām | blocks 8.2.77–78 lengthening | churati |

These are the known gaps. Full paradigms may show more; the builder fixes those by
the slice-1 rules (correct meta-rules, never ordering hacks), and anything that
needs a design decision goes back to the user.

**ṛch and uch.** Slice 1.5 stored bhvādi yuch and uch with cch, because 6.1.73 che
ca and 7.3.86 guṇa bled each other. In tudādi, 1.1.5 blocks guṇa before śa, so the
conflict does not arise: tudādi ṛch and uch keep their taught single ch and the
trace shows 6.1.73. The note in `docs/findings.md` that planned cch for them is
corrected.

**Voice.** Some tudādi roots have special voice rules (e.g. 1.3.61 for mṛ, which
only affects other tenses). The marker-based voice is cross-checked against Vidyut,
as in slice 1.5.

## Display

- **7.1.59 historical aside:** "historically a nasal-infix present; cf. Lat.
  *rumpit*, Skt. rudhādi". Same "Read via" / aside pattern as the 7.3.78 asides.
- **3.1.77 aside:** the class continues the Indo-European *tudé-* type, accented
  on the thematic vowel (accent itself is not modelled yet).
- Modern terms first, Pāṇinian terms in tooltips, as everywhere.

## Lexicon

- Vendor the tudādi section as `src/panini/data/dhatupatha_tudadi.tsv` from
  Vidyut's `dhatupatha.tsv` (entries starting `06.`), via
  `scripts/vendor_dhatupatha.py`.
- `Root.gana` comes from the list code (`01.` bhvādi, `06.` tudādi) instead of the
  hard-coded "bhvādi". The present-affix rules key on it.
- Search, the server and the CLI pick up the new roots unchanged; the explorer
  shows the class next to the root.

## Checking

- `scripts/make_reference.py` passes the root's gaṇa to Vidyut (today it
  hard-codes `Gana.Bhvadi`) and regenerates the fixture.
- **Fast tests:** a couple of plain roots (tud, diś) and one or two roots per new
  rule.
- **Full sweep:** the existing `slow` test covers tudādi too. Goal: 100% agreement
  on in-scope roots; remaining differences listed and explained in
  `docs/findings.md`.

## Approaches considered

- **A. Whole class, swept against Vidyut (chosen).** The zero grade is nearly free
  (1.2.4 and 1.1.5 already exist), so the cost is the short rule list above.
- **B. A handful of hand-picked roots.** Rejected: slower for a slice that is mostly
  free, and the hand-checked treatment is reserved for slice 2.0.
- **C. Tudādi plus curādi.** Rejected: curādi needs derived stems (ṇic), a separate
  slice.
