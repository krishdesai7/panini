# Slice 1.6 (tudādi, laṭ/laṅ) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Derive laṭ and laṅ for every tudādi root (list codes `06.`), with each new rule a cited step, matching Vidyut.

**Architecture:** The lexicon gains a second vendored section and `Root.gana` comes from the list code; the root Term carries its gaṇa as a tag so rules can key on it. 3.1.77 is an apavāda of 3.1.68 (śa for śap); the existing 1.2.4 + 1.1.5 then give the zero grade. The other new rules are ordinary `Rule`s in the existing rule modules, ordered by the resolver as today (no ordering hacks).

**Tech Stack:** Python via uv, pytest, Vidyut (dev group only, for the reference fixture).

**Spec:** `docs/superpowers/specs/2026-11-26-slice-1.6-tudadi-design.md`

## Global Constraints

- Every new rule gets a `sutras.toml` entry (text + plain gloss) and, where the sūtra carries words over, a `readings.py` entry; notes use `{modern|traditional}` markup, modern term first.
- Never fix a wrong form by reordering rules or special-casing a derivation; fix the meta-rule or the rule's conditions. Anything needing a design decision goes back to the user.
- Vidyut stays dev-only; the runtime reads only vendored files.
- Run everything through uv: `uv run pytest`, `uv run --group dev python scripts/…`. The repo's CI gate is `just -g ci` (ruff, complexipy, pyrefly).
- Keep slice-1.5 behaviour: the fast suite and the slow bhvādi sweep stay green after every task.

## Review Focus

1. **Readings keyed by spelling.** `scripts/vendor_dhatupatha.py` rewrites `uCI~` → `ucCI~` by dhatu string; tudādi `06.0015 uCI~` must keep its single ch. Test in Task 1.
2. **Names now shared across classes.** `uch` (01.0244, 06.0015), `ṛch` (01.1086 is ṛ; 06.0016 ṛch), `nud` (06.0002, 06.0162) — lookup must raise `AmbiguousRoot` rather than silently pick one, and `TAUGHT_AS` must not hide 06.0015. Test in Task 1.
3. **Tudādi rules leaking into bhvādi.** 3.1.77, 6.4.24, 7.1.59 and 6.4.77 must not fire on bhvādi roots (śap is pit, so not ṅit). Test in Tasks 2–4: a bhvādi root with a penultimate nasal (kampate 01.0435) and one ending in u (bhavati 01.0001) are unchanged and their traces don't mention the new rules.
4. **Middle-voice paradigms.** jh endings after śa (tudante), and middle-only roots (mriyate). Tests in Tasks 2 and 4.
5. **Out-of-scope tudādi roots.** `06.0159 viCa~` forms an -āya- stem (vicchāyati, 3.1.28) and must show an availability reason, not a wrong form. Test in Task 1.
